# 🤖 The Interview Agent

An AI-powered technical interviewer built for the Vibe Code Hackathon. It conducts rigorous, multi-turn technical interviews across multiple engineering domains, dynamically evaluates user answers, tracks live scores across Correctness, Clarity, Depth, and Communication, and generates a comprehensive hiring report.

## 🚀 Live Demo
[View Live Application](https://interview-agent-delta-plum.vercel.app)

## ✨ Key Features
- **Multi-Domain Support:** Interview questions tailored for Frontend, Backend, Data Structures & Algorithms, System Design, DevOps & Cloud, and Machine Learning.
- **Strict Answer Evaluation:** Analyzes candidate text depth, penalizing short or negative responses (e.g., "no") while rewarding complete technical explanations.
- **Live Scorecard:** Real-time tracking of Correctness, Clarity, Depth, and Communication scores.
- **Comprehensive Hiring Report:** Generates a final score, competency breakdown, key strengths, and growth areas upon completion.

## 🛠️ Tech Stack
- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS & Framer Motion
- **AI Integration:** Google Gemini API (`gemini-1.5-flash`)
